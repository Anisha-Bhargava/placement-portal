Placement Portal Application
A Flask-based web application for managing campus recruitment activities, connecting institutes, companies, and students in an efficient placement management system.
Overview
This Placement Portal streamlines the campus recruitment process by providing role-based access to Admin (Institute), Companies, and Students. It manages company registrations, placement drives, student applications, and maintains comprehensive placement records.
Tech Stack

Backend: Flask
Frontend: Jinja2, HTML, CSS, Bootstrap
Database: SQLite
Authentication: Role-based access control
